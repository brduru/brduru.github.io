# brduru..github.io

Repositório da GitHub Pages para publicar artigos em Markdown.

## Como publicar um novo artigo

1. Crie um arquivo em `_posts/` no formato:
   `AAAA-MM-DD-titulo-do-artigo.md`
2. Adicione o front matter no topo:

   ```markdown
   ---
   title: "Título do artigo"
   ---
   ```
3. Escreva o conteúdo em Markdown abaixo do front matter.

Ao fazer push para a branch publicada no GitHub Pages, o artigo aparece automaticamente na página inicial.
